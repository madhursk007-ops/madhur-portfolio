# WorkSuite — Enterprise Digital Workspace

An integrated browser prototype combining three practical digital-workplace workflows: issue tracking, knowledge documentation, and spreadsheet-friendly operational reporting.

## Live demo
https://madhursk007-ops.github.io/madhur-portfolio/projects/worksuite/

## Modules

### Project board
- Create issues with summary, owner, priority, type and description.
- Track work through To Do, In Progress and Done.
- Search and filter by priority.
- View issue counts and status distribution.

### Knowledge base
- Create, categorize, search, edit and delete articles.
- Capture how-to guides, meeting notes, technical decisions and runbooks.
- Keep documentation organized for repeatable team processes.

### Reports and spreadsheet workflow
- View completion, priority and status summaries.
- Import issue registers from CSV.
- Export the issue register to CSV for spreadsheet applications such as Microsoft Excel.

## Run
Open `index.html` in a modern browser. No build step or third-party dependency is required.

## Technology
HTML, CSS, JavaScript, localStorage, browser File API and CSV parsing/export.

## Scope and limitations
This is an independent portfolio prototype inspired by common project-management and knowledge-management workflows. It is **not** connected to Jira, Confluence, Microsoft Excel, Microsoft 365, or Power BI. CSV is a spreadsheet-compatible exchange format, not a native Excel workbook integration. Data is stored in the current browser only; there is no authentication, shared backend, access control, audit log, or multi-user synchronization.

Sample records are illustrative. Do not enter confidential or personal information.
