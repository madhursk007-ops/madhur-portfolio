# Madhur Khadabadi — Portfolio

React-powered personal portfolio built with React, JavaScript and Vite.

## Local development
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
npm run preview
```

GitHub Actions builds the site and deploys the `dist` folder to GitHub Pages on pushes to `main`.
